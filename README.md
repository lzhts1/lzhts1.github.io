# GitHub Pages 个人主页

这是一个无构建步骤的静态个人主页。`wallpaper.mp4` 是全屏、静音、循环的视频背景；页面在视频未加载或无法播放时会显示薰衣草色底图，保证文字仍可阅读。

## 本地查看

直接在浏览器打开 `index.html` 即可预览；也可以在 VS Code 中使用 Live Server 等任意静态服务器扩展。

## 发布到 GitHub Pages

1. 将这些文件推送到仓库。个人主页仓库名应为 `你的GitHub用户名.github.io`。
2. 在仓库的 **Settings → Pages**，选择从 `main` 分支根目录部署。
3. 等待部署完成后，访问 `https://你的GitHub用户名.github.io`。

## 下一步填写内容

页面中所有 `[方括号]` 内的文本都是占位内容。后续可依次完善：个人介绍、项目、近况、联系方式与社交链接。

## 头像

将你的头像放在与 `index.html` 同一目录，并命名为 `avatar.jpg`。页面会在图片加载成功后自动显示它；没有该文件时，则保留设计好的头像占位框。推荐使用清晰的正方形或竖向人像，主体居中。

> `wallpaper.mp4` 当前约 61 MB，低于 GitHub 单文件 100 MB 限制，但首次打开会较慢。正式发布前建议压缩为 8–15 MB 的 H.264 MP4，以改善移动网络体验。
